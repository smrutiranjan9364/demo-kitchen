# Static assets

Place the site logo here as **`logo.png`** (the "Odia Kitchen" logo).

The app references it at `/logo.png` from:
- `components/layout/Header.tsx` (storefront header)
- `components/layout/MobileNav.tsx` (mobile drawer)
- `components/admin/LoginForm.tsx` (admin login page)
- `components/admin/AdminShell.tsx` (admin sidebar, expanded)

A transparent-background PNG is recommended (it sits on the plum header/sidebar).
